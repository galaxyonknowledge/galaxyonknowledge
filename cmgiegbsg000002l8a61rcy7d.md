### Setting Up ChatGPT Bots in WhatsApp

There is no official WhatsApp app from OpenAI. You have two main paths, both simple to try.

* Use a third-party WhatsApp bot: search for services that clearly state they use the OpenAI API. Look for a real website, a privacy policy, contact details, and recent user reviews.
    
* Use a connector with the WhatsApp Business API: tools like Twilio or automation platforms can link your number to the OpenAI API. This fits teams or power users.
    

Steps to add a free or low-cost bot:

1. Pick a trusted provider with free messages to test.
    
2. Start a chat by tapping the provided WhatsApp link or scanning a QR code.
    
3. Read the welcome message. It should explain limits, pricing, and data use.
    
4. Send a first prompt, for example, “Summarize this text in 3 lines,” then paste your text.
    
5. Save the contact and pin the chat for quick access.
    

Safety checks that protect you:

* Avoid bots that ask for passwords, bank info, or codes.
    
* Do not share private data in chats.
    
* If you set up your own bot with an API key, keep the key private and rotate it if exposed.
    
* If in doubt, stop using the bot and delete the chat.
    

Example you can try: “You are a travel guide. Plan a 2-day food tour in Austin with 3 must-try spots.”
